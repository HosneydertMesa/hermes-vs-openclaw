# Hermes vs OpenClaw

A side-by-side comparison of [Hermes Agent](https://github.com/NousResearch/hermes-agent) and [OpenClaw](https://github.com/Honkonx/termux-ai-stack), built as a static site with [Astro 7](https://astro.build) + [Tailwind 3](https://tailwindcss.com).

The site itself was authored by **Hermes Agent** running on a **$200 Android tablet** with **Termux** — see the [field report](src/pages/blog/termux-field-report.astro) for the full story.

> ⚠️ Not affiliated with Nous Research. This is an independent, community-built comparison.

## What's here

- **9 sections** — hero, side-by-side comparison, features grid, layered architecture, use cases, pricing, FAQ, blog preview, footer
- **3 pages** — `/`, `/blog/`, `/blog/termux-field-report/`
- **22KB CSS bundle**, **122KB total dist**, **1.3s build**
- Dark theme, custom design tokens (Inter / Instrument Serif / JetBrains Mono), subtle animations, fully responsive

## Stack

| Layer | Tool |
|---|---|
| Static site generator | Astro 7.1.6 |
| Styling | Tailwind CSS 3.4 + custom design system in `src/styles/global.css` |
| Type safety | TypeScript strict (`tsconfig.json` extends `astro/tsconfigs/strict`) |
| Build target | Static HTML, no SSR, deployable anywhere |
| Source | Hand-authored MDX-free `.astro` components |

## Run it locally

```bash
npm install              # one-time, ~30s
npm run build            # outputs to ./dist/
npm run preview          # serves dist/ on http://localhost:4321 (or next free port)
npm run dev              # dev server with HMR on http://localhost:4321
```

> 💡 **Termux note**: `npm run` works here because scripts call `node ./node_modules/astro/bin/astro.mjs` directly. On standard Linux/macOS you can simplify to `"build": "astro build"` — the symlinks in `node_modules/.bin/` resolve correctly there.

## Design system

The site uses a dark-first palette with a single accent color (`accent-500` ≈ `#7a3aff`). All colors, spacing, animations, and component classes live in `tailwind.config.mjs` + `src/styles/global.css`.

Common component classes (defined in `@layer components`):

| Class | Purpose |
|---|---|
| `container-page` / `container-narrow` | Page max-widths |
| `pill` | Small inline tag with optional pulse dot |
| `card` / `card-feature` | Bordered surfaces with hover lift |
| `gradient-text` | White → accent text gradient |
| `btn-primary` / `btn-ghost` | Pill buttons |
| `eyebrow` | Tiny uppercase label above headings |
| `badge-soft` / `badge-positive` / `badge-negative` | Inline status chips |

Animations: `fade-up`, `fade-in`, `pulse-soft`, `float`, `marquee` (defined as keyframes in the Tailwind config).

## Deploy

The `dist/` folder is a self-contained static site. Drop it on any of:

- **Cloudflare Pages** — `wrangler pages deploy dist/`
- **Vercel** — `vercel deploy --prebuilt`
- **GitHub Pages** — push `dist/` to `gh-pages` branch
- **Netlify** — drag-and-drop `dist/` to the dashboard
- **Local nginx/caddy** — point document root at `dist/`

A `404.html` is not generated by default. If you need one, add `src/pages/404.astro`.
